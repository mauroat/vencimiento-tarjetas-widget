# widget-vencimiento-tarjetas

Widget customizable para utilizar como recordatorio de las fechas de cierre y vencimiento de la tarjeta de crédito
_Customizable widget for use as reminder of credit card's Statement date and Due date_

## Versión
* 1.0

## Requirements
* iOS
* Scriptable app

## Installation
* Crear dos scripts en la app Scriptable
* Llamar al primero **UpdateWidgetDates** y al segundo **WidgetDates**
* Agregar el widget a la pantalla principal del dispositivo iOS
